# 🩸 Blood Bank Management System

A web-based Blood Bank Management System built using **PHP and MySQL** to manage blood donors, blood groups, blood requests, donor records, and administrative operations through a centralized platform.

## 📌 About the Project

The Blood Bank Management System provides a simple platform for managing blood donation and blood request activities.

The system allows users to register as blood donors, maintain their profiles, search for available donors, and submit blood requests. An administrative panel is also included for managing donor records and other system operations.

## ✨ Features

### 👤 User Features

- User registration and login
- Donor profile management
- Blood donor registration
- Search for donors based on blood group
- View donor information
- Submit blood requests
- Contact and enquiry functionality
- Change password functionality

### 🔐 Admin Features

- Secure admin login
- Manage donor records
- View and manage blood-related requests
- Manage registered users
- Administrative dashboard
- Manage system information

## 🛠️ Technologies Used

- **PHP** – Backend development
- **MySQL** – Database management
- **HTML5** – Page structure
- **CSS3** – Styling
- **JavaScript** – Client-side functionality
- **Bootstrap** – Responsive user interface
- **XAMPP** – Local development environment
